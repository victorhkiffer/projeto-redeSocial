# Stack (decisão v1)

## Banco de dados
- PostgreSQL
- Migrações SQL versionadas em `db/migrations`

## Frontend
- React + TypeScript (pendente de Node.js no ambiente)
- Rotas: React Router
- UI/tema: Tailwind (com modo claro/escuro usando CSS variables)

## Backend (proposta v1)
- API HTTP (REST) com autenticação JWT + refresh token
- Implementação: a decidir quando o ambiente estiver pronto (Node.js recomendado para ecossistema React/Prisma; alternativa: outra stack caso necessário)
